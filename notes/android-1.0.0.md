Android 1.0.0（versionCode 15）

与 iPad 1.0.0 对齐，手机、折叠屏和平板共用同一安装包。

- 新增设置：平板在左侧栏底部，手机在“更多 → 设置”。包含主题颜色、阅读方式与翻页效果、重新显示操作说明、储存位置、软件更新、崩溃记录、问题反馈和版本信息。
- 主题颜色：石墨（默认）、墨蓝、松绿、靛紫、酒红、琥珀，浅色和深色模式均适用，切换后立即生效；界面底色改为中性灰白。
- 崩溃记录：记录程序崩溃；Android 11 起还记录应用无响应、原生崩溃和前台内存不足退出。记录只保存在本机，下次打开时可选择上传、查看或以后再说；上传后会在发行仓库的反馈页生成问题。设置中可关闭、查看和删除。
- 排序新增“自定义”：在“调整顺序”中长按 PDF 拖到想要的位置，顺序自动保存。
- 添加外部来源后，可在“我的设备”和各只读来源之间切换，全部、最近、收藏和分类只显示当前位置的 PDF。
- 多选后可删除（会先确认）；只读来源中的 PDF 改为“复制到本机”。
- 空资料库显示欢迎页；应用图标换为新图稿。

Android 8.0 及以上；沿用原有签名，可覆盖安装并保留数据。安装由系统确认。已在 API 35 手机和平板模拟器上验证，尚未在真机上测试。
