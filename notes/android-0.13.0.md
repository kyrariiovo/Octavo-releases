# Octavo Android 0.13.0

继续同步 iPad 0.11–0.13.0 的书签、阅读工具栏与节目单改动。

- 标注按钮一键进入；标注界面顶部直接提供撤销、重做、手指书写和完成。撤销状态随真实笔迹更新，完成后保留纸面并立即保存；默认仅笔书写，手指仍可翻页和缩放。
- 页面菜单提供文档更改撤销／重做与原 PDF 标记移除，没有可识别原标记时禁用；检测在后台进行。页面结构编辑继续使用保存／放弃事务，撤销保留在编辑事务内。
- 新增页面书签：添加／移除当前页、按页排序跳转、轻扫或长按移除；横屏双页可分别添加。书签自动保存在本地，跟随原页面重排；删除页时隐藏，撤销后恢复。节目单共用来源 PDF 的书签，并显示来源文件与页码。
- 页码滑条下方显示书签位置，密集标记合并；点按标记直接跳转，拖动靠近时轻微吸附，继续拖动可以脱离。拖动缩略预览显示书签状态，松手才翻页；键盘和无障碍逐页调整。
- 底部工具栏改为左右各三项，中间页码与总页数等宽对齐；整体最大宽度960dp，左右与底部保留一致留白。手机和窄折叠屏采用两行布局，保留原生触控目标和五秒隐藏。
- 节目单整行可直接进入连续阅读；空节目单进入编辑。列表右侧只保留文字“编辑”，删除放在长按菜单与详情确认中，源 PDF 和标注保留。

Android 8.0 及以上，沿用现有兼容签名，可直接覆盖安装。书签保存在应用本地元数据中，不重写原 PDF；单独复制 PDF 不包含书签。本轮使用 Android 原生控件与系统分享，未连接真机进行手感或性能测量。
