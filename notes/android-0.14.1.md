# Octavo Android 0.14.1

新增适合看谱的渐进翻页，并继续对齐 iPad 0.14.1 的阅读改动。

- “阅读 → 阅读方式”新增“渐进翻页 · 自由分界”。上下拖动可在任意位置逐渐揭开下一页，松手停住，不固定半页；反向拖动可退回，拖到边缘完成一页。记录每份 PDF／节目单的分界进度，左右侧仍可翻整页；双指缩放或书写时先回到触及的完整页面。此模式按单页整页显示，支持裁剪留白。
- 全屏隐藏系统状态栏与导航栏，工具显隐保持纸面尺寸稳定；系统边缘手势仍可临时唤出系统栏。首页／末页区域移到顶部工具栏下方，帮助分区同步更新，翻页提供短暂方向提示。
- 标注新增 HSV 色盘、颜色代码、最近使用的十二种颜色，以及连续调整明度、不透明度和粗细的滑条。颜色面板的完成按钮固定在顶部；颜色和线条设置会记住。笔迹透明度在保存、PNG 截图和 PDF 导出中保持一致，兼容旧笔迹记录。
- 手动进入标注可立即用手指书写；手写笔自动进入仍保留手指翻页策略。翻页中断后先完整落页，再开始标注。顶部文件候选增至十份，返回直接回文件库。
- 渐进翻页复用当前及相邻纸面，最多保留三个页面视图；拖动不新增页面视图或发起新的纸面渲染请求，松手后再维护相邻缓存。修复手势结束后保留旧页面引用的问题；调色不重新绘制已有纸面与笔迹。

Android 8.0 及以上，沿用原签名，可覆盖安装。PDF 与新增笔迹仍分别保存在托管文件和应用本地元数据中；导出 PDF 时可包含笔迹。布局与功能在 API35 模拟器验证，厂商平板／折叠屏的手写笔手感及帧率仍需真机验证。
