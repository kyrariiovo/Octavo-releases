# Octavo Android 0.10.0

同步 iPad 近期的阅读布局、节目单和性能改动，适配安卓手机、折叠屏与平板。

- 竖屏单页、横屏双页，支持横向滑动／层叠和竖向连续阅读。快速连点直接调整当前动画目标，反向从可见页接手；页码在落页后保存。
- 全新紧凑阅读工具栏、最多五个 PDF／节目单标签、拖动页码时的浮动缩略图。静置五秒隐藏阅读工具，纸面尺寸保持稳定。
- 页面大小支持整页、适合宽度、四边裁剪留白与固定裁剪；设置分别记忆，原 PDF 页面和标注坐标保留。
- 新增节目单：编排多份 PDF 并连续阅读、拖动排序、跨曲目跳转；源文件与标注共用，删除节目单保留 PDF。
- 手写笔接触页面自动进入标注，保留当前画布；仅笔书写时手指仍可翻页和双指缩放。标注时隐藏阅读工具，右上角可直接完成。支持撤销、重做及移除可识别的原有 PDF 标注。
- 页面编辑加入保存／放弃／继续编辑、重做、空白页和多页拖动；分类移除会将文件移回未分类。
- 当前整页可截图保存至相册、文件或分享；提供单独的附近分享入口。附近传输方式由设备系统的快速分享／互传服务提供。
- 后台渲染、共享页面内存及磁盘缓存、按方向预热和内存压力回收；旋转复用原生翻页容器，稳定后再补清晰度。缓存按 Android 的实际进程内存上限调整。

Android 8.0 及以上；保持现有应用名称与兼容签名，可直接覆盖安装。PDF、节目单和新增标注均保存在本地。已压平进页面图像的标记不能单独移除。安卓使用原生手写输入与系统分享，不包含 Apple PencilKit 或 AirDrop。
